# MixIt

A desktop app for DJ mixing, arranging, editing and mixing songs, built so a beginner makes a good-sounding mix in the first minute and a pro can trust it for a full set.

- **Engine:** Rust, real-time safe, sample-accurate, the same code for live playback and offline rendering.
- **Shell:** Tauri 2 (Windows, macOS, Linux).
- **UI:** React and TypeScript, GPU-drawn waveforms and meters.

The plan lives in the MixIt Plan document; repository docs are under `docs/`.
